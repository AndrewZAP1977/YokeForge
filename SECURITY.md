## English

### Supported versions

| Version | Supported |
|---|---|
| 0.1.0 | Yes |
| Earlier versions | No |

### Reporting a security vulnerability

Do not report security vulnerabilities through public GitHub Issues.

Use GitHub private vulnerability reporting from the repository Security page.

Security reports may be written in English, Russian, or German.

Please include:

- the affected YokeForge version;
- Windows version;
- a clear description of the vulnerability;
- steps required to reproduce it;
- the possible impact;
- relevant logs or screenshots;
- whether the issue may affect force-feedback hardware safety.

Do not include:

- passwords;
- access tokens;
- private keys;
- personal account information;
- Microsoft Flight Simulator SDK files;
- proprietary third-party files.

### Hardware safety

Unexpected, continuous, or dangerous force-feedback movement must be treated as a hardware safety problem.

Disconnect motor power immediately and stop using YokeForge.

Ordinary hardware safety reports may be submitted with the **Safety problem** Issue form. A hardware problem that also exposes a security vulnerability should be reported privately.

### Disclosure

Please allow reasonable time to investigate and correct a reported vulnerability before publishing technical details.

YokeForge is an independent project and does not provide a guaranteed response time or service level.

## Русский

### Поддерживаемые версии

| Версия | Поддержка |
|---|---|
| 0.1.0 | Да |
| Более ранние версии | Нет |

### Сообщение об уязвимости

Не публикуй сведения об уязвимостях через обычные публичные GitHub Issues.

Используй приватную отправку отчёта об уязвимости на странице Security репозитория.

Сообщения можно писать на английском, русском или немецком языке.

Укажи:

- затронутую версию YokeForge;
- версию Windows;
- понятное описание уязвимости;
- шаги для её воспроизведения;
- возможные последствия;
- необходимые журналы или скриншоты;
- может ли проблема влиять на безопасность оборудования Force Feedback.

Не публикуй:

- пароли;
- токены доступа;
- закрытые ключи;
- личные данные учётных записей;
- файлы Microsoft Flight Simulator SDK;
- проприетарные файлы сторонних разработчиков.

### Безопасность оборудования

Неожиданное, постоянное или опасное движение устройства Force Feedback следует считать проблемой безопасности оборудования.

Немедленно отключи питание моторов и прекрати использование YokeForge.

Обычные проблемы безопасности оборудования можно отправлять через форму **Safety problem**. Если проблема одновременно является уязвимостью программного обеспечения, сообщи о ней приватно.

### Публикация сведений

Не публикуй технические подробности уязвимости до завершения её проверки и исправления.

YokeForge является независимым проектом и не предоставляет гарантированный срок ответа или уровень обслуживания.

## Deutsch

### Unterstützte Versionen

| Version | Unterstützt |
|---|---|
| 0.1.0 | Ja |
| Frühere Versionen | Nein |

### Sicherheitslücke melden

Sicherheitslücken dürfen nicht über öffentliche GitHub Issues gemeldet werden.

Für Sicherheitsmeldungen ist die private Schwachstellenmeldung auf der Security-Seite des Repositorys zu verwenden.

Berichte können auf Englisch, Russisch oder Deutsch verfasst werden.

Bitte angeben:

- betroffene YokeForge-Version;
- Windows-Version;
- klare Beschreibung der Sicherheitslücke;
- Schritte zur Reproduktion;
- mögliche Auswirkungen;
- relevante Protokolle oder Screenshots;
- ob die Sicherheit der Force-Feedback-Hardware betroffen sein kann.

Nicht veröffentlichen:

- Passwörter;
- Zugriffstoken;
- private Schlüssel;
- persönliche Kontodaten;
- Dateien des Microsoft Flight Simulator SDK;
- proprietäre Dateien anderer Anbieter.

### Hardwaresicherheit

Unerwartete, dauerhafte oder gefährliche Force-Feedback-Bewegungen müssen als Hardwaresicherheitsproblem behandelt werden.

Die Motorstromversorgung sofort trennen und YokeForge nicht weiter verwenden.

Normale Hardwaresicherheitsprobleme können über die Vorlage **Safety problem** gemeldet werden. Wenn das Problem gleichzeitig eine Software-Sicherheitslücke darstellt, muss es privat gemeldet werden.

### Veröffentlichung

Technische Einzelheiten einer Sicherheitslücke sollen erst nach angemessener Prüfung und Behebung veröffentlicht werden.

YokeForge ist ein unabhängiges Projekt und bietet keine garantierte Antwortzeit oder Servicevereinbarung.
