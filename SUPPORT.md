## English

YokeForge uses GitHub Issues for bug reports and feature requests.

### Before opening an issue

Please:

1. Make sure you are using the latest official YokeForge release.
2. Check the existing Issues to see whether the problem has already been reported.
3. Restart YokeForge and Microsoft Flight Simulator 2024.
4. Confirm that the force-feedback device is calibrated.
5. Try to reproduce the problem using clear and repeatable steps.

### Open an issue

Use the [YokeForge issue tracker](https://github.com/AndrewZAP1977/YokeForge/issues).

Issues may be written in English, Russian or German.

Choose the appropriate form:

- **Bug report** — ordinary software problem;
- **Safety problem** — unexpected or dangerous device movement;
- **Feature request** — proposal for a new feature.

### Information to include

A useful bug report should contain:

- YokeForge version;
- Windows version;
- Microsoft Flight Simulator 2024 version;
- aircraft being used;
- force-feedback device and relevant hardware modifications;
- whether the problem occurs with the autopilot on or off;
- exact steps needed to reproduce the problem;
- expected behaviour;
- actual behaviour;
- screenshots when they help explain the problem;
- relevant YokeForge logs, when available.

Before uploading a log, review it and remove personal information that is not needed for the report.

Do not upload:

- passwords;
- access tokens;
- private keys;
- personal account information;
- Microsoft Flight Simulator SDK files;
- proprietary third-party files;
- unrelated system information.

### Hardware safety problems

If the device creates an unexpected, continuous or dangerous force:

1. Disconnect motor power immediately.
2. Stop using YokeForge.
3. Do not repeat the test until the cause is understood.
4. Open an Issue using the **Safety problem** form.
5. Describe what happened immediately before the unsafe movement.

Do not attempt to work around safety limits or automatic disarming in order to repeat a test.

### Feature requests

Feature requests may also be submitted through GitHub Issues.

Please describe:

- the problem the proposed feature would solve;
- the expected behaviour;
- the hardware or aircraft involved;
- why the existing controls are insufficient.

A submitted request does not guarantee that the feature will be implemented.

### Unsupported configurations

Support cannot be guaranteed for:

- modified or repackaged YokeForge binaries;
- downloads obtained from unofficial mirrors;
- untested force-feedback devices;
- manually modified safety limits;
- damaged or incorrectly wired hardware;
- unofficial changes to Microsoft Flight Simulator;
- third-party aircraft modifications that change required telemetry.

### Response times

YokeForge is an independent project. No guaranteed response time, service level or continuous technical support is provided.

## Русский

Для сообщений об ошибках и предложений YokeForge использует GitHub Issues.

### Перед созданием обращения

Перед созданием Issue:

1. Убедись, что используешь последнюю официальную версию YokeForge.
2. Проверь, не сообщал ли кто-нибудь об этой проблеме раньше.
3. Перезапусти YokeForge и Microsoft Flight Simulator 2024.
4. Убедись, что устройство Force Feedback откалибровано.
5. Постарайся определить понятную последовательность действий, которая повторяет проблему.

### Создание обращения

Открой [страницу Issues YokeForge](https://github.com/AndrewZAP1977/YokeForge/issues).

Обращения можно писать на английском, русском или немецком языке.

Выбери подходящую форму:

- **Bug report** — обычная ошибка программы;
- **Safety problem** — неожиданное или опасное движение устройства;
- **Feature request** — предложение новой функции.

### Что указать

Полезное сообщение об ошибке должно содержать:

- версию YokeForge;
- версию Windows;
- версию Microsoft Flight Simulator 2024;
- используемый самолёт;
- модель устройства Force Feedback и важные изменения его конструкции;
- состояние автопилота;
- точную последовательность действий;
- ожидаемое поведение;
- фактическое поведение;
- скриншоты и журналы YokeForge, когда они помогают понять проблему.

Перед публикацией журнала проверь его и удали ненужные личные данные.

Не публикуй:

- пароли;
- токены доступа;
- закрытые ключи;
- личные данные учётных записей;
- файлы Microsoft Flight Simulator SDK;
- проприетарные файлы сторонних разработчиков;
- ненужные сведения о системе.

### Опасное поведение устройства

Если устройство создаёт неожиданное, постоянное или опасное усилие:

1. Немедленно отключи питание моторов.
2. Прекрати использование YokeForge.
3. Не повторяй проверку, пока причина не будет понятна.
4. Создай обращение через форму **Safety problem**.
5. Опиши, что происходило непосредственно перед опасным движением.

Не отключай защитные ограничения или автоматическое снятие усилий для повторения опасной ситуации.

### Предложения функций

Предложения также принимаются через GitHub Issues.

Опиши:

- какую проблему должна решить функция;
- ожидаемое поведение;
- используемое оборудование или самолёт;
- почему имеющихся возможностей недостаточно.

Создание обращения не гарантирует реализацию функции.

### Неподдерживаемые конфигурации

Поддержка не гарантируется для:

- изменённых или перепакованных файлов YokeForge;
- загрузок из неофициальных источников;
- непроверенных устройств Force Feedback;
- вручную изменённых защитных ограничений;
- повреждённого или неправильно подключённого оборудования;
- неофициальных изменений Microsoft Flight Simulator;
- модификаций самолётов, изменяющих необходимую телеметрию.

### Срок ответа

YokeForge является независимым проектом. Гарантированный срок ответа и постоянная техническая поддержка не предоставляются.

## Deutsch

YokeForge verwendet GitHub Issues für Fehlerberichte und Funktionsvorschläge.

### Vor dem Erstellen eines Issues

Bitte:

1. Prüfen, ob die neueste offizielle YokeForge-Version verwendet wird.
2. Vorhandene Issues auf denselben Fehler durchsuchen.
3. YokeForge und Microsoft Flight Simulator 2024 neu starten.
4. Prüfen, ob das Force-Feedback-Gerät kalibriert ist.
5. Klare und wiederholbare Schritte zur Reproduktion ermitteln.

### Issue erstellen

Die [YokeForge-Issue-Seite](https://github.com/AndrewZAP1977/YokeForge/issues) öffnen.

Issues können auf Englisch, Russisch oder Deutsch verfasst werden.

Die passende Vorlage auswählen:

- **Bug report** — normaler Softwarefehler;
- **Safety problem** — unerwartete oder gefährliche Gerätebewegung;
- **Feature request** — Vorschlag für eine neue Funktion.

### Erforderliche Informationen

Ein hilfreicher Fehlerbericht sollte enthalten:

- YokeForge-Version;
- Windows-Version;
- Version von Microsoft Flight Simulator 2024;
- verwendetes Flugzeug;
- Force-Feedback-Gerät und relevante Hardwareänderungen;
- Zustand des Autopiloten;
- genaue Schritte zur Reproduktion;
- erwartetes Verhalten;
- tatsächliches Verhalten;
- hilfreiche Screenshots und YokeForge-Protokolle.

Vor dem Hochladen eines Protokolls müssen nicht benötigte persönliche Daten entfernt werden.

Nicht hochladen:

- Passwörter;
- Zugriffstoken;
- private Schlüssel;
- persönliche Kontodaten;
- Dateien des Microsoft Flight Simulator SDK;
- proprietäre Dateien anderer Anbieter;
- nicht benötigte Systeminformationen.

### Sicherheitsprobleme der Hardware

Wenn das Gerät unerwartete, dauerhafte oder gefährliche Kräfte erzeugt:

1. Die Motorstromversorgung sofort trennen.
2. YokeForge nicht weiter verwenden.
3. Den Test nicht wiederholen, bis die Ursache verstanden wurde.
4. Die Vorlage **Safety problem** verwenden.
5. Beschreiben, was unmittelbar vor der gefährlichen Bewegung geschah.

Sicherheitsgrenzen oder automatische Kraftabschaltungen dürfen nicht umgangen werden, um den Test zu wiederholen.

### Funktionsvorschläge

Funktionsvorschläge können ebenfalls über GitHub Issues eingereicht werden.

Bitte beschreiben:

- welches Problem gelöst werden soll;
- das erwartete Verhalten;
- die beteiligte Hardware oder das Flugzeug;
- warum die vorhandenen Funktionen nicht ausreichen.

Ein Vorschlag garantiert keine Umsetzung.

### Nicht unterstützte Konfigurationen

Unterstützung kann nicht garantiert werden für:

- veränderte oder neu verpackte YokeForge-Dateien;
- Downloads aus inoffiziellen Quellen;
- nicht getestete Force-Feedback-Geräte;
- manuell veränderte Sicherheitsgrenzen;
- beschädigte oder falsch angeschlossene Hardware;
- inoffizielle Änderungen an Microsoft Flight Simulator;
- Flugzeugmodifikationen, die erforderliche Telemetriedaten verändern.

### Antwortzeiten

YokeForge ist ein unabhängiges Projekt. Eine garantierte Antwortzeit oder dauerhafte technische Unterstützung wird nicht angeboten.
